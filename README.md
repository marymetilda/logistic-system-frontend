# Logistics Route Optimization Dashboard

A minimal frontend dashboard built using React.js and Tailwind CSS for testing and demonstrating the logistics route optimization backend system.

The dashboard provides real-time route optimization, route management, analytics, and operational controls for logistics delivery networks.

---

# Features

- Route optimization between hubs
- Dynamic traffic management
- Route block/unblock controls
- Top 5 fastest route analytics
- Real-time operational dashboard
- Integrated backend API communication

---

# Tech Stack

- React.js
- Tailwind CSS
- Axios
- Vite

# Environment Variables

Create a `.env` file in the root directory.

```env
VITE_API_URL=http://localhost:5000/api
```

---

# Installation & Setup

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

# Backend Requirement

Ensure the backend server is running before starting the frontend application.

Backend API should run on:

```txt
http://localhost:5000
```
